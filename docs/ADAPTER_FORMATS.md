# Supported formats and evidence — 2026-11-20

No personal session files were inspected. All repository fixtures are synthetic. `verified` means fixture tests plus real-format evidence; `fixture-tested` explicitly falls short of live/user-log qualification. CSV routes are `manual`. Registry, CLI doctor and UI use the same five statuses.

- GitHub/Gitee: M1/M2 opt-in public requests through CLI and actual dev proxy; never retain responses. See acceptance records.
- GitLab/Codex: M1 synthetic fixtures; fixture-tested, no current real check.
- Claude: [ccusage parser](https://github.com/ccusage/ccusage/blob/main/rust/adapters/claude/src/lib.rs), [official monitoring semantics](https://code.claude.com/docs/en/monitoring-usage). Assistant usage: input + cache creation + cache read becomes inclusive input; output stays output. Message ID/request ID revision key; replay echoes suppressed. Local reader is explicit --claude-dir; no Claude discovery in our test runs. Supported profile is fixture-tested, not producer-version-certified.
- Gemini: [official chat recording types](https://github.com/google-gemini/gemini-cli/blob/main/packages/core/src/services/chatRecordingTypes.ts). Full conversation JSON or append-only message JSONL. Input includes cached tokens; tool prompt counts add to input, thoughts add to output. Reported total must reconcile; other accounting profiles fail rather than guess. Patch/rewind/checkpoint JSONL is unsupported: use full conversation JSON. Fixture-tested.
- Cursor: [official release notes](https://cursor.com/docs/release-notes/web) document CSV export, [Admin API](https://cursor.com/docs/account/teams/admin-api) documents disjoint categories. Personal CSV exact column schema is not pinned by an official sample; manual importer supports the DESIGN column profile and rejects accounting mismatches. No cookies or account database access. CSV timestamps are bucketed in the selected system/IANA timezone; preview shows this policy. Cache-write/uncached/cache-read are disjoint then mapped inclusively.
- Manual: `date,source,metric,value,timezone,quality`; anonymous source IDs, safe nonnegative integers, explicit units/timezone. Duplicate dates require reconciliation. UTF-8/BOM first, GB18030 fallback; preview before import. The encoding guess is shown and is not a guarantee of original encoding.

Imports replace the active workspace after preview; multiple files with duplicate source series fail. A local parser never retains prompts/code/path content in a bundle. Export geometry carries no raw observations or printable name metadata; visible engraved text remains inherently present in the mesh.

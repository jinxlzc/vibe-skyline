## VERIFIED DATA FACTS (coordinator ran real requests / read official docs on 2026-11-20; prefer these over guesses)
- **GitHub public calendar**: `GET https://github.com/users/<u>/contributions?from=YYYY-01-01&to=YYYY-12-31` → 200 HTML, no auth; 365 `data-date` cells with `data-level` 0-4; exact counts only inside `<tool-tip>` text ("4 contributions on January 4th."). **No CORS header** → browser needs CLI or a tiny proxy. GraphQL `contributionsCollection` needs a token (unauth → 403) but gives exact counts + private contributions (if the user enabled it). REST `/users/<u>/events/public` is only ~90 days.
- **Gitee**: `GET https://gitee.com/<u>/contribution_calendar?year=YYYY` (X-Requested-With: XMLHttpRequest) → 200 `text/javascript` with HTML cells `data-content='N个贡献：YYYY-MM-DD' date='YYYYMMDD'`; no auth; default = rolling last 12 months; `?year=2024` returned 2023-12-31..2024-12-31. Coordinator tested public handles (redacted). OpenAPI v5 `/api/v5/users/<u>` and `/events/public` work with `Access-Control-Allow-Origin: *` but events are sparse/limited (not a calendar). Unofficial endpoint → fixture tests.
- **GitLab**: `GET https://gitlab.com/users/<u>/calendar.json` → `{"YYYY-MM-DD":count}` rolling ~12 months, no auth, no CORS header. Self-hosted GitLab same path.
- **Codex CLI (coordinator format check, codex-cli 0.169.1)**: `~/.codex/sessions/YYYY/MM/DD/` may hold `.jsonl.zst` and `.jsonl` files; also `~/.codex/archived_sessions/`. Lines `{timestamp, ordinal, type:"event_msg", payload:{type:"token_count", info:{total_token_usage, last_token_usage, model_context_window}, rate_limits}}`; usage keys input_tokens, cached_input_tokens, cache_write_input_tokens, output_tokens, reasoning_output_tokens, total_tokens. Node 24 `zlib.zstdDecompressSync` decodes them natively (no extra dep in CLI). Private usage figures redacted: **local history can be sparse/short**. Codex cloud tasks / ChatGPT usage: no public per-user token export found → out of scope (manual).
- **Claude Code**: `~/.claude/projects/**/*.jsonl` (+ `~/.claude/transcripts/`, `~/.config/claude/projects/`); `message.usage`. Caveat: Claude Code deletes transcripts older than `cleanupPeriodDays` (default 30) unless the user raised it → **history depth often only 30 days**; design must surface coverage and encourage "start collecting now" (CLI `--snapshot` that appends daily aggregates to `~/.vibeskyline/ledger.json`).
- **Gemini CLI**: `~/.gemini/tmp/<projectHash>/chats/*.json(l)`, `messages[]` with `type:"gemini"`, `tokens:{input, output, cached, thoughts, tool, total}` (cached ⊂ input), `model`, `timestamp` (from gemini-cli source `chatRecordingTypes.ts`; ccusage + tokscale parse it).
- **Antigravity CLI (agy format example)**: `~/.gemini/antigravity-cli/conversations/*.db` SQLite (tables steps, gen_metadata, trajectory_meta…, protobuf blobs). tokscale reads it directly (MIT core → reference implementation). IDE ext: `~/.gemini/antigravity/conversations/*.db`.
- **Cursor**: no token counts on disk. Personal data only via **undocumented dashboard endpoints** with the session cookie (`/api/dashboard/export-usage-events-csv?strategy=tokens`, `/api/dashboard/get-filtered-usage-events`); session JWT can be read from `state.vscdb` key `cursorAuth/accessToken` (tokscale/agent-walker do this). Official Admin API is **team-only**. → Default path: user downloads CSV from dashboard and drops it; cookie-auto-sync = opt-in, labelled unofficial (ToS risk medium).
- **GitHub Copilot**: CLI local `~/.copilot/session-store.db` (`assistant_usage_events`) + `~/.copilot/otel/*.jsonl`; personal billing: Settings → AI usage CSV (≤31 days per export) and REST `GET /users/{u}/settings/billing/premium_request/usage?year=&month=&day=` (premium requests, not tokens; 24 months).
- **DeepSeek**: public API key can only read `/user/balance`. Daily token buckets only via **private platform endpoints** with the web session token (`platform.deepseek.com/api/v0/usage/by_api_key/amount?start&end&tz`, `/api/v0/usage/export?month&year` → ZIP of amount-YYYY-M.csv). → Default: user exports CSV from console usage page (≤30-day UI window; monthly export) and drops it; session-token sync opt-in/unofficial. Local: DeepSeek Harness `~/.dsh/sessions/**/session.jsonl.zstd`; DeepSeek models used inside Claude Code/OpenCode are attributed via model name.
- **Kimi / Moonshot**: **official Admin API** (Admin Key, `billing:read`): `GET https://api.moonshot.cn/v1/admin/organizations/usage/completions?start=<ms>&end=<ms>&granularity=1d` (≤93 days/window, CST day boundaries; prompt/completion/cached tokens, request_count); daily bills retained 365 days; request details 90 days. Local: Kimi CLI `~/.kimi/sessions/`, Kimi Code `~/.kimi-code/sessions/`.
- **Qwen**: Qwen Code keeps a local ledger `~/.qwen/usage/token-usage-YYYY-MM.jsonl` and has `/stats export daily|monthly --format csv|json` (official); also `~/.qwen/projects/`. Bailian/Model Studio: `bl monitor metrics --metric model_input_amount,...` CLI / console.
- **Zhipu GLM / Z.ai**: no public token-usage history API for pay-as-you-go (console "费用账单 → 导出记录" CSV only). Coding Plan: `GET https://open.bigmodel.cn/api/monitor/usage/quota/limit` (or api.z.ai) returns only quota percentages (not history). Local: ZCode `~/.zcode/cli/db/db.sqlite`; GLM via Claude Code model names.
- **Doubao / Volcengine Ark**: **official OpenAPI** `GetInferenceUsage` (AK/SK signed; StartTime/EndTime yyyy-MM-dd, QueryInterval=Day; InputTokens/OutputTokens/TotalTokens/ReqCnt; filter by ApiKeyID); `arkcli usage stats --interval Day`; ListBillDetail monthly (≤24 months). Agent/Coding Plan: GetAFPUsage / GetUsageDetails.
- **Trae**: personal edition shows **credits, not tokens**; enterprise console exports token detail; tokscale syncs via account API. **CodeBuddy**: CLI `~/.codebuddy/projects/**/*.jsonl` (+ `/cost`); web usage page shows credits. **通义灵码 (Tongyi Lingma)**: no personal token export found → manual/credits.
- **Aggregator imports**: `tokscale graph --output data.json` (60+ agents) and `ccusage daily --json` already normalize most local agents → first-class importers.

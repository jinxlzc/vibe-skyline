# M4 synthetic protocol examples

All activity here is synthetic. No owner logs, real-name coupons, private paths or raw prompts are included.

- `activity.schema.json`, `spec.md`, `synthetic.bundle.json`: the same v2 protocol served by the app.
- `offline-pack.zip`: those three files, deterministic archive timestamps.
- `synthetic-activity.stl`, `synthetic-activity.3mf`: actual Playwright browser downloads after importing the synthetic bundle; independently reopened and mesh/3MF validated.
- `summary.json`: SHA-256 hashes and validation labels.

The model uses neutral `skyline-demo`, VibeSkyline Grid and original replaceable assets. Units are mm. Material groups are mapped to filament in the user's own slicer. No printer profile is included. **Real logos ON by default: NOT satisfied. Not sliced or physically printed.**

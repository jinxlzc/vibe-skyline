# M3 review exports — public calendar and SYNTHETIC import

These are actual browser downloads reopened for STL mesh / Core 3MF validation, with SHA-256 hashes in [summary.json](summary.json). **Not sliced / not physically printed. Bambu A1 material mapping unverified. Real logos ON by default: NOT satisfied.** No owner real-name coupons are included.

- `public-github-live.bundle.json`: real public GitHub `torvalds` calendar, year 2026, fetched through the restricted local relay. Only public per-day calendar values and requested username are retained. No private account, OAuth, AI logs or signed-in data. The returned 365 date cells include the provider's future/zero cells; this is not a guarantee of complete history.
- `public-github-live-recorded.stl` / `.3mf`: browser generated from that recorded response (the test intercepts the exact calendar URL and replays the saved real response). The evidence banner says **LIVE-RECORDED PUBLIC**, and the engraving is the public username. The exports are not generated by a live browser network request at test time.
- `SYNTHETIC-advanced.bundle.json`: seven-day synthetic Codex series with `sample: true` and synthetic provenance. No real tool usage or personal files. Sample identities are intentionally ignored; engraving stays `skyline-demo`.
- `SYNTHETIC-advanced.stl` / `.3mf`: actual browser exports from that optional import. These demonstrate fixture support only, not live AI qualification.

Reproduce from the repo root after `pnpm install --frozen-lockfile`:

```sh
LIVE=1 pnpm test:live        # optional refresh of real public evidence; may fail with upstream connectivity
pnpm -r build
pnpm exec playwright test tests/online.spec.ts
```

Without the saved public bundle, the browser test uses a clearly labeled synthetic GitHub fixture and emits `public-github-fixture.*` instead. No synthetic response is claimed to be a live account. Existing public bundles allow offline replay; see timestamps and response hashes in [live evidence](../../acceptance/m3-live.json).

Core 3MF preserves multi-material geometry and slot intent, not a validated Bambu project. STL is a mono union. Purge and slice time remain unknown. Usernames and activity-derived shapes remain visible in models even though raw activity metadata is excluded.

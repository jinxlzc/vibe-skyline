# Public release checklist

**This private feature branch is not a public-release approval. No deploy, npm publish, PR, merge or visibility change occurred.**

Current M6 scope and validation are in [M6_NOTES.md](../M6_NOTES.md); model evidence is in [examples/m5](../examples/m5/README.md). Historical milestone reports are not current website instructions. Review these remaining gates before public launch:

- [ ] Owner explicitly approves public visibility, deployment and any package publication separately.
- [x] GitHub official Invertocat is the public default; Gitee's official white mark is also bundled. Owner accepted residual brand-policy risk; no redistribution/printable-derivative grant is claimed. Global/per-source UI and build-time kill switches exist. [File provenance, remaining 16 placeholders and restrictions](../licenses/TRADEMARKS.md). Both marks remain not print-qualified; GitHub's measured gap is ~0.538 mm.
- [ ] GitLab retains a reserved plate; any future official artwork needs separate provenance and geometry review.
- [ ] Exact-version Bambu Studio/Orca imports preserve printer/process profiles, named parts and physical filament intent. Core 3MF sidecars are instructions, not verified automatic mapping. See BAMBU_A1_FIXTURES_NEEDED.md.
- [ ] Physical A1 coupons and objects: confirm CJK counters/strokes, original tiles, local SVGs, two-tone boundary, adhesion and tolerances. Record nozzle/layer/material/version and photographs. No physical proof exists yet.
- [ ] Feature measurement limits: text uses eight-direction opposing-wall calipers; pointed terminals and unsampled irregular walls are not certified. SVG adds contour clearance/bottleneck checks within a bounded profile. Generic minimum-feature and arbitrary-surface proof remain open.
- [ ] Full shaping: M2 uses NFC scalar/grapheme-aware Han/Latin fallback, not HarfBuzz contextual shaping. Unsupported sequences fail clearly. Font coverage does not guarantee every name fits the bed at required feature size.
- [ ] GitLab real public calendar qualification; keep beta until live evidence exists.
- [ ] Expanded malformed calendar/SVG/font corpora, keyboard/screen-reader/contrast audit, actual mobile/WeChat devices, operating-system matrix.
- [ ] Source SBOM, dependency audit, hosted relay protections and operational privacy review if hosting is proposed. Current proxy is local dev/preview only.
- [ ] Performance targets beyond first-load JS: Single-source CAD+3MF <6s, peak memory <512MiB, sub-300ms interactions and real mobile timings need pinned benchmarks.

Activity protocol and raw-log adapters remain internal, outside M6 website release gates. `/protocol/v2/*` must not distribute protocol content in dev, preview or the production build.

Current first-run defaults: one source per model, GitHub official Invertocat, Gitee official white mark, explicit public username or `skyline-demo`, VibeSkyline Grid, printer-agnostic material groups. This establishes neither slicing, physical printing, trademark grants nor public-launch approval. Historical private-name packets have been retired from the current tree; publishing Git history requires a deliberate privacy review.

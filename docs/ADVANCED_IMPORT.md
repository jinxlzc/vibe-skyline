# Retired website activity import

M6 supports only GitHub, Gitee and GitLab (beta) public contribution calendars. The advanced activity-import panel, file/drop handler, agent prompt and `/protocol/v2/` public files have been removed. There is no activity-file import workflow in this version.

Protocol implementation, schemas and synthetic fixtures remain in `packages/contracts`; CLI adapters and node readers remain internal utilities. They are not reachable through the website UI. Historical M3/M4 reports record the earlier import workflow.

See the current [English quickstart](QUICKSTART_en.md) or [中文快速开始](QUICKSTART_zh.md).
